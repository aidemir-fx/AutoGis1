# Favicon файлы

Для полной SEO оптимизации необходимо создать следующие favicon файлы:

## Обязательные файлы:
- `favicon.ico` (32x32) - основной favicon
- `favicon-32x32.png` (32x32) - PNG версия
- `favicon-16x16.png` (16x16) - маленькая версия
- `apple-touch-icon.png` (180x180) - для iOS устройств
- `icon-192x192.png` (192x192) - для PWA
- `icon-512x512.png` (512x512) - для PWA

## OG изображения:
- `og-image.jpg` (1200x630) - для социальных сетей
- `twitter-image.jpg` (1200x600) - для Twitter

## Логотип:
- `logo.png` (рекомендуемый размер 200x60) - логотип компании

## Как создать:
1. Используйте онлайн-генераторы favicon (favicon.io, realfavicongenerator.net)
2. Или создайте в графических редакторах (Figma, Photoshop, GIMP)
3. Разместите файлы в папке `/public/`

## Цветовая схема:
- Основной цвет: #1976d2 (Material-UI blue)
- Фон: #ffffff (белый)
